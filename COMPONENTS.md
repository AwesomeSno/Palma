# Listing all the components needed to build this project. 

## Electronic Components

- ESP32-S3 
- BNO085 IMU (the motion sensor)
- LiPo battery (around 500mAh with protection circuit)
- MCP73831 charger chip
- 3.3V regulator (TLV75533P)
- USB-C connector
- Coin vibration motor + transistor to drive it.
